How to Guide for CODEX CLI Setup

Use this quick guide to connect Codex CLI with InternMate MCP over HTTP and start role-based task operations.

Setup Steps
  1. Start InternMate Django app on http://127.0.0.1:8000.
  2. Set MCP env vars: INTERNMATE_BASE_URL, INTERNMATE_API_USERNAME, INTERNMATE_API_PASSWORD.
  3. Run MCP server on http://127.0.0.1:9001/mcp.
  4. Add MCP server in Codex CLI config with transport=\"http\" and URL http://127.0.0.1:9001/mcp.
  5. Restart Codex CLI and validate with tools list call.
Expected MCP Tools
  • InternMate_get_daily_logs
  • InternMate_get_task
  • InternMate_update_task
  • InternMate_list_interns
  • InternMate_list_projects
API Documentation

Core InternMate REST endpoints and supported verbs:

Endpoint Supported Verbs Notes
/api/daily-logs/ GET, POST List and create daily task logs.
/api/daily-logs/{id}/ GET, PUT, PATCH, DELETE Detail/update/delete based on role permissions and visibility.
/api/daily-logs/{id}/workflow/ POST Workflow action endpoint (DRAFT/SUBMITTED/REVIEWED/REOPENED/CLOSED).
/api/interns/, /api/interns/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Intern profile management.
/api/projects/, /api/projects/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Project master management.
/api/departments/, /api/departments/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Department master management.
/api/intern-assignments/, /api/intern-assignments/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Intern-project assignment mapping.
/api/master-data-lists/, /api/master-data-lists/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Dropdown list definitions.
/api/master-data-items/, /api/master-data-items/{id}/ GET (+ POST/PUT/PATCH/DELETE admin-only) Dropdown list values.
/api/ai-usage/, /api/ai-usage/{id}/ GET, POST, PUT, PATCH, DELETE Responsible AI usage records linked to tasks.
/api/review-comments/ GET List mentor/manager review comments.
/reports/export/?format=csv|xlsx|pdf GET Export filtered report output in supported formats.
Authentication: Session auth and Basic auth enabled for API access.
Role controls: Several master endpoints allow write verbs only for Admin role.
MCP note: InternMate MCP server currently uses HTTP transport and calls these APIs with Basic Auth credentials.
