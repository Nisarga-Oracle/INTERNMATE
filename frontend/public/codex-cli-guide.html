CODEX CLI Guide

A short guide for working safely with the InternMate project from your local terminal.

Start the application

cd "C:\Users\Nisarga\Downloads\InternMate\InternMate\InternMate"
.\.venv-win\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8001

Open http://127.0.0.1:8001. Stop the server using Ctrl + C.

What Codex helps with

Codex can inspect the code, make scoped changes, build the React interface, test the FastAPI service, and help diagnose Oracle ATP connection errors. It should not be given passwords, wallet contents, or copied credentials.

Useful checks

npm.cmd run build
.\.venv-win\Scripts\python.exe .\seed_demo_workspace.py

The build verifies the frontend. The seed command is safe to repeat and creates missing demo records only.
